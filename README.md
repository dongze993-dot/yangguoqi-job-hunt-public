# 央国企岗位投递看板 · 方法论开源版

> 一个面向 **2025 届 / 两年择业期内未就业毕业生** 的央国企（央企 / 省属国企 / 市属国企）岗位筛选系统。
> 岗位数据来自公开招聘公告，**不含任何个人信息**。

---

## 这是什么

一套「企业树驱动 + 双轴判定」的央国企岗位筛选看板，把找工作这件事从**海投**变成**有框架的定向排查**。

核心洞察：**在央国企秋招季，2025 届身份几乎已经被关闭**。真正有效的窗口只有两类——

1. **公告明文写「择业期内未就业毕业生 / 两年择业期」的企业**（极少数）
2. **不限届别的社招通道**（要求 1-3 年经验，需要提前攒经验）

所以这个系统的价值不是「帮你找到好岗位」，而是**告诉你哪些窗口真的开着、哪些已经关了**。

## 筛选方法论（可复用到其他央国企/省属招聘）

### 一、Filter × Access 双轴体系

把「岗位适不适合」和「门槛高不高」彻底分开：

- **Fit（能力匹配）**：岗位需要的能力 vs 我的真实经历
- **Access（准入门槛）**：届别 / 专业 / 经验 / 英语 / 性质 / 薪资 / 学历
- **Evidence（证据等级）**：A 官方系统 · B 官方公众号或高校网 · C 企业官方账号平台 · D 第三方线索
- **Action（行动）**：现在到底该做什么

**关键原则**：届别不符 ≠ 岗位不匹配。机械淘汰会错杀大量「能力完全够、只差届别」的机会——这些应该标 J-C 长期跟踪，而不是直接删除。

### 二、薪资必须按档位判，不能拍脑袋

| 档 | 年包 | 判定 |
| --- | --- | --- |
| S | 20万+ | 极高，优先投 |
| A | 15-20万 | 高，优先投 |
| B | 12-15万 | 正常投 |
| C | 8-12万 | 降权（211 背景应追 15万+） |
| D | <8万 | 排除 |
| **U** | **未公开** | **待核，≠ 低薪**（未公开不得判低薪） |

### 三、企业树驱动，不是岗位驱动

```
Step 1  建立目标集团池（央企99家分档 + 省市国资委体系）
Step 2  集团 → 直接子公司全景
Step 3  重点子公司 → 三级/专业公司/区域主体
Step 4  每个重点节点查招聘入口（企业名+招聘/社招/采购/供应链/物流…）
Step 5  搜当前岗位
Step 6  Fit × Access × Evidence × Action
Step 7  J-A/B/C/D 分类
Step 8  无岗位但高价值的企业 → T-Watch 池
```

**三条防漏规则**：
1. 一个岗位 ≠ 一个集团扫描完成（必须继续查兄弟公司/专业公司）
2. 一个二级公司 ≠ 该二级公司扫描完成（继续查三级）
3. **无岗位 ≠ 无价值**（高价值无岗位企业进 T-Watch，不删除）

### 四、T-Watch 池：给「暂时没岗位」的企业留位置

高价值但当前无岗位的企业**不淘汰**，单独进跟踪池。因为这类企业通常有长期滚动招聘、社招常年开放（浙商中拓就是「招到即止」），等 1 年经验后就是主力通道。

### 五、证据分级与层级不得猜测

- 证据等级 A > B > C > D，D 级线索只能当方向，不能当结论
- 企业层级（集团/一级/二级/三级/专业公司/区域公司）**不确定就写「待核」**，不准猜
- `TREE-COMPLETE` vs `TREE-PARTIAL` 要标清楚——**禁止把「岗位搜索完成」误报成「企业树搜索完成」**

### 六、硬红线（不妥协项）

- 不要一线 / 下矿 / 施工现场 / 长期驻场
- 不要倒班、不定时工作制
- 不要有销售压力（纯销售、客户经理、出单、核保、理赔）
- 城市办公室优先
- 正式劳动合同 + 五险一金（不接受派遣/外包）

## 求职策略层结论

1. **找岗位 > 完全匹配**——央国企不看重对口经历，能力标签宽口径投，让 HR 去筛
2. **学历背景要追高薪**——211 校招背景不该接受 7-8K 档
3. **两条腿并行**：校招投归校招，社招经验同步攒；等 1 年经验，14-16万那批单证/商务岗全线打开
4. **C 档例外规则**：如果「很好进 + 内容简单 + 福利好」，优先级可以上调
